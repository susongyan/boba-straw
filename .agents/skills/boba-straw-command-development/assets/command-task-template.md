# 命令扩展任务模板

将以下内容复制到任务，按需要填写；可推导的项目约束不必重复填写。
这是任务输入模板，不是已实施或已授权的清单。

```text
使用 boba-straw-command-development，在 Boba Straw 源码中完成以下任务。

模式：开发 / 只读审查
目标：数据结构、命令、子命令或选项
排除范围：本次不做的部分
兼容范围：服务端及版本、拓扑；未指定时先核对仓库已有目标
API 范围：同步/异步、String/byte[]；未指定时先列出现有覆盖及缺口
前置能力：是否允许扩展连接/协议/路由；超出范围先说明
测试环境：已有测试地址和可用版本（不要填写生产凭证）
环境操作：是否允许启动测试环境；未说明不由 Skill 授权
提交与推送：是否允许，以及阶段要求

先检查源码和工作树，再按命令形式分类，按验收清单实施或审查。
交付实际运行结果、未验证项、兼容性影响、限制及后续动作。
```
