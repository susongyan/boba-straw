# 命令扩展验收清单

选择适用项并报告结果，不以“全部勾选”代替证据。
通用约束见 [AGENTS.md](../../../../AGENTS.md)，高风险复核见
[审查 Skill](../../boba-straw-review/SKILL.md)。

| 编号 | 适用范围 | 验收要求 |
| --- | --- | --- |
| CMD-01 | 所有命令形式 | 官方参数/选项版本有来源；正常、边界、空结果和服务端错误有测试 |
| CMD-02 | 参数编码 | 参数次序、可变数量、互斥组合正确；拒绝行为与既有 API 一致 |
| CMD-03 | 公共接口 | Java 8；源码及二进制兼容性复核；不添加核心外部运行时依赖 |
| CMD-04 | 二进制/文本接口 | 非 UTF-8、空 byte[]、空字符串与 null 区分；往返不损坏数据 |
| CMD-05 | 返回映射 | RESP2/RESP3 差异正确，空聚合/空值/嵌套结构不会误映射 |
| CMD-06 | 解码器改动 | 字节级分片、多帧、畸形输入、Push/Attribute 和 FIFO 回归 |
| CMD-07 | 路由 | Key 提取及 Hash Tag；多 Key 同 Slot/跨 Slot 策略；无 Key 节点选择 |
| CMD-08 | 阻塞/状态型 | 专用连接；取消、超时、部分写出/已写出、关闭及回收/销毁路径 |
| CMD-09 | 异步/失败 | Future 可终止；不隐藏“可能已执行”；不增加自动重试，不因异常类型简单判定可重试 |
| CMD-10 | Pipeline/事务适用 | FIFO、部分错误和结果映射；批量不冒充原子性，事务不承诺回滚 |
| CMD-11 | 共享内核改动 | 相关并发及生命周期回归；持有资源有明确所有者和释放路径 |
| CMD-12 | 文档与支持声明 | 公开示例与真实 API 一致；区分实现和环境验证，Raw 不冒充类型化支持 |

最低执行根目录 `mvn test`。按任务运行真实服务端集成及兼容性测试，记录版本、协议、拓扑。
模拟服务端测试不能证明真实 Redis/Valkey 兼容性。缺少 JDK/服务端矩阵的结果分别标记未运行。
非内核普通命令变更不强制全量压测；性能敏感改动说明需要的基线和负载。
已有失败不得通过删除测试、放宽超时或忽略异常来“修绿”；先区分环境问题与实现问题。

交付证据格式：

```text
范围：命令形式、选项、API 与未覆盖项
基线：提交 + 是否包含工作树修改
兼容性：公共接口变化及影响
验证：CMD 编号；测试类/方法；命令；环境；结果；报告位置
未验证：维度与原因；后续动作
限制：连接/拓扑/版本等已知边界
```

Skill 格式和链接校验不代表行为验证。人工需确认语义、资源所有权和兼容性；
没有独立 Agent 试运行时不得声称跨模型验证通过。
